Status: —

Exports all 16 tables as a single JSON file downloaded to your device. The file is your only backup — store it in Google Drive, email it to yourself, or keep it in a safe folder. Financial data only; no passwords or API keys are included.

Note on Documents table: Documents only stores names and links (e.g. Google Drive URLs). The actual files referenced are NOT downloaded — those remain wherever you stored them externally.

Note on Authentication: Your login password is managed by Supabase Auth and is NOT included in this backup. If you lose access, you must recreate your account — your financial data can then be re-imported.
